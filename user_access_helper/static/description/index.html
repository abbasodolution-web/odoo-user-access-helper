User Access Helper

See which user accounts are a risk, fix them in bulk, and keep a record of every access change

Admins without two-factor authentication, accounts nobody has used for months, people who left but can still log in, API keys nobody remembers: they are invisible in the standard Users list. This module shows them on one screen, lets you act on many users at once, and logs who gave whom which rights.

What it does

  • Security Overview: every user's admin rights, 2FA, last seen, idle days, open sessions and API keys.
  • Risk flags: Admin without 2FA, Unused account (90+ days) and Never logged in, sorted to the top, with filters for each.
  • Access Actions for one user or many, from the Users list or the Overview:
    • Set a new password, or generate a strong one and copy it
    • Send a password reset email
    • Disable 2FA for a lost phone (trusted devices are removed too)
    • Log out of all devices (stolen laptop, shared computer)
    • Revoke API keys
    • Deactivate (offboarding): archive, end every session and revoke API keys in one step, and Reactivate
  • A reason on every action and a live summary before you apply ("3 sessions will be ended").
  • Access rights change log: whenever anyone adds or removes a group on a user, it is recorded automatically, with Admin rights granted flagged. Only the groups that were chosen are listed, not the dozens implied by them.
  • One audit log: what, for whom, done by whom, when, from which IP address and why.
  • Safe by design: Odoo's own password re-check before every change; you cannot deactivate yourself or the last administrator, and your own session is never ended.
  • Settings administrators only. Depends on base, auth_totp and auth_signup. Covered by 16 automated tests.

Setup

Nothing to configure. Install it and open Settings › Users & Companies › Security Overview or User Access Log. Access rights changes are logged from the moment the module is installed.
