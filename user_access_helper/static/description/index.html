User Access Helper

Reset passwords and disable 2FA for your users in one click, with an audit log.

"I forgot my password" and "I lost my phone, I can't log in" are the most common support tickets. This module lets Odoo administrators fix both straight from the Users list, for one user or many, and records every change.

Installation

Install in 3 steps

1
Get the app
Click Download on this page (free).
2
Add it to Odoo
Unzip it into your custom add-ons folder (a folder listed in addons_path) and restart Odoo. On Odoo.sh, push the folder to your repository instead.
3
Install it
Turn on developer mode, open Apps › Update Apps List, search User Access Helper and click Activate.
How to use

Use it

1
Reset passwords
Settings › Users, select one or more users, Actions › Reset Password, type the new password twice (8+ characters) and confirm with your own password.
2
Disable 2FA for a lost phone
Select the user, Actions › Disable 2FA. Trusted devices are revoked too, so the user can set up 2FA again.
3
Check the log
Settings › Users & Companies › User Access Log: who did what, for whom and when.

Does it work on Odoo Online (SaaS)?
No. Odoo Online does not allow apps from the store. It works on Odoo.sh and on your own server, Community or Enterprise.
