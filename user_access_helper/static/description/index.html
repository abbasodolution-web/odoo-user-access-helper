User Access Helper

See which user accounts are a risk, fix them in bulk, and keep a record of every access change

Admins without two-factor authentication, accounts nobody has used for months, people who left but can still log in, API keys nobody remembers: they are invisible in the standard Users list. This module shows them on one screen, lets you act on many users at once, and logs who gave whom which rights.

What you get

What it does

✓
Security Overview
Every user's admin rights, 2FA, last seen, idle days, open sessions and API keys.
✓
Risk flags
Admin without 2FA, Unused account (90+ days) and Never logged in, sorted to the top, with filters for each.
✓
Access Actions
For one user or many, from the Users list or the Overview: set a new password or generate a strong one, send a password reset email, disable 2FA for a lost phone (trusted devices are removed too), log out of all devices (stolen laptop, shared computer) and revoke API keys.
✓
Deactivate (offboarding)
Archive, end every session and revoke API keys in one step, and Reactivate
✓
A reason on every action
And a live summary before you apply ("3 sessions will be ended").
✓
Access rights change log
Whenever anyone adds or removes a group on a user, it is recorded automatically, with Admin rights granted flagged. Only the groups that were chosen are listed, not the dozens implied by them.
✓
One audit log
What, for whom, done by whom, when, from which IP address and why.
✓
Safe by design
Odoo's own password re-check before every change; you cannot deactivate yourself or the last administrator, and your own session is never ended.

Installation

Install in 3 steps

1
Get the app
Click Download on this page (free).
2
Add it to Odoo
Unzip it into your custom add-ons folder (a folder listed in addons_path) and restart Odoo. On Odoo.sh, push the folder to your repository instead.
3
Install it
Turn on developer mode, open Apps › Update Apps List, search User Access Helper and click Activate.
How to use

Use it

1
Nothing to configure
Access rights changes are logged from the moment the module is installed.
2
Find risky accounts
Settings › Users & Companies › Security Overview: admins without 2FA, unused accounts and accounts that never logged in come first.
3
Fix them in bulk
Select users and use Access Actions (also in the Users list under Actions). Give a reason; a summary shows what will happen before you apply.
4
Offboard a leaver
Deactivate archives the user, ends every session and revokes API keys in one step.
5
Check the log
Settings › Users & Companies › User Access Log.
FAQ

Good to know

Does it work on Odoo Online (SaaS)?
No. Odoo Online does not allow apps from the store. It works on Odoo.sh and on your own server, Community or Enterprise.

Can I lock myself out?
No. You cannot deactivate yourself or the last administrator, and your own session is never ended.
Who can use it?
Settings administrators only.
