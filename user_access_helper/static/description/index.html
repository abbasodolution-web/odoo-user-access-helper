User Access Helper

Reset passwords and disable 2FA for your users in one click — with an audit log.

"I forgot my password" and "I lost my phone, I can't log in" are the most common support tickets. This module lets Odoo administrators fix both straight from the Users list, for one user or many, and records every change.

Key features

  • Bulk password reset — set a new password for all selected users at once (8+ characters, typed twice)
  • Disable 2FA — turn off two-factor authentication and revoke trusted devices for users who lost their device
  • Odoo's own security check — the admin confirms their password before any change
  • Audit log — who did it, for whom and when, under Settings › Users & Companies
  • Admins only — actions and log are visible to Settings administrators only
  • Tested — covered by automated tests; depends only on base and auth_totp

1. Reset passwords in bulk

Settings › Users › select users › Actions › Reset Password

2. Disable 2FA for a lost device

Actions › Disable 2FA — trusted devices are revoked so the user can set it up again

3. Every change in the audit log

Settings › Users & Companies › User Access Log
